# 轻营平台导览：角色与基本使用

轻营（LingMart）是一套 C2C 电商交易平台，任何用户都能注册、开店、发布闲置或自营商品，买家下单购买，双方在线聊天沟通。

## 三种身份角色

- ROLE_USER 普通买家：浏览商品、加购物车、下单支付、管理订单、与卖家聊天。
- ROLE_SELLER 卖家（入驻审核通过后获得）：拥有「我的店铺」与「卖家中心」，可管理店铺、发布商品、处理订单发货、查看经营数据。
- ROLE_ADMIN 管理员：通过「管理后台」（路由 /admin/review）审核开店申请、审核商品、处理异常。

普通用户注册后默认是买家；申请开店并通过管理员审核后升级为卖家。管理员不进入商城购物流程。

## 常见入口（路由）

- / 首页（店铺列表为入口，可浏览商品）
- /login、/register 登录与注册（页面右上角）
- /cart 购物车、/orders 我的订单
- /shop/apply 申请开店
- /my-shop 我的店铺（查看开店审核进度与结果）
- /seller 卖家中心（商品管理、发货、经营数据、订单导出）
- /chat 消息（与卖家/买家实时聊天）
- /admin/review 管理员审核中心

## 帮助与反馈

- 商品、订单、发货、退款等**交易类问题**：优先通过「消息」（/chat）联系对应卖家。
- 开店申请、商品审核**进度与结果**：在「我的店铺」（/my-shop）与「卖家中心」（/seller）查看。
- 平台目前**没有面向买家的管理员工单入口**——与卖家协商不成时，请在订单详情中先申请退款，由卖家审核处理。

## 关于浮窗助手（Copilot）

页面右下角的 🤖 浮窗是平台内置的智能助手，能：解答平台使用问题、带你跳到指定页面、点击页面上你确认过的按钮，
还能**根据你提供的商品清单预填开店申请**（清单可以直接粘贴，或点输入框左边的 📎 上传 CSV / Excel / Word 文件；只是草稿，提交仍由你自己点）。
它**不能**替你下单、支付或改价，也**不代填开店申请以外的任何表单**——涉及资金和敏感信息的操作一律由你本人完成。
详见知识库《浮窗助手使用说明》。

# 卖家中心：发货、经营数据与导出

入口：页面右上角用户菜单 →「卖家中心」（/seller）。只有开店审核通过的卖家能看到完整功能。

## 一、订单管理：发货

- 买家付款后，订单进入「已支付」，需要**你（卖家）手动发货**。
- 在卖家中心 → 订单管理里找到该订单，点「发货」。
- 发货是卖家的动作，**买家无法自行把订单变成已发货**。
- 发货后订单变为「已发货」，等买家点「确认收货」才会变成「已完成」。

> 平台**不需要填快递单号**——没有对接物流，发货只是一个状态标记。
> 具体的物流信息请通过「消息」和买家沟通。

## 二、处理退款申请

买家申请退款后，你能在订单管理里看到这笔待审核的申请：

- **通过**：订单变为「已退款」，交易关闭；系统自动**回补库存**、**扣减该商品累计销量**。
- **拒绝**：**必须填写拒绝原因**才能提交，买家能看到原因，并可以修改理由再次申请。

## 三、经营数据看板

卖家中心提供经营看板，支持切换时间范围：

- **近 7 天（7d）** / **近 30 天（30d）** / **全部（all）**

看板内容：

- **概览**：销售额等核心指标
- **状态分布**：各订单状态占比
- **趋势**：按时间的销售额/订单量走势
- **热销 TOP5**：卖得最好的前 5 个商品

> 看板数据与订单列表口径一致。「已退款」的订单不计入销售额。

## 四、订单导出（Excel）

- 卖家可以按**最近 N 天**导出自己的订单明细为 Excel（.xlsx）文件。
- 导出是**流式生成**的，数据量大时也不会把服务打挂。
- 买家同样可以在自己的订单列表导出**自己的**订单，两者数据互不可见。

## 五、商品与库存管理

- 发布 / 编辑 / 上下架商品：见《卖家：商品发布、审核与上下架》
- 改库存**不触发重新审核**，随时可改
- 库存支持「不限量」模式，适合可无限供应的商品

## 六、常见问题

- **“销售额怎么少了？”** 如果最近有退款通过的订单，它们会从销售额里扣除，这是正常口径。
- **“导出文件打不开/乱码？”** 请用 Excel 或 WPS 打开；导出文件是带中文表头的 xlsx，
  已按 UTF-8 处理，如果显示乱码请检查打开方式（不要用纯文本编辑器）。
- **“能导出买家信息吗？”** 不能。导出的是**你自己店铺订单**的信息，不含其他买家的数据。
- **“店铺改名后商品还正常吗？”** 正常。改名进入待重审，重审期间旧店名照常营业；
  通过后系统会重建该店铺商品的搜索索引，所以搜索结果里的店名也会同步更新。

# 购物车与结算下单

## 一、加入购物车

- 商品详情页选好规格（SKU）和数量，点「加入购物车」，入口在页面右上角「购物车」（/cart）。
- **同一商品同一规格只会有一条购物车记录**：重复加购不会产生两行，而是**累加数量**。
  不同规格是不同 SKU，各占一行。
- 不限量商品也可以加购，不受库存数量约束。
- **加购会校验商品状态**：加购时要向商品服务确认该 SKU 存在且可售，
  所以「未上架 / 未通过审核 / 已下架」的商品**加不进购物车**，
  会直接提示失败（而不是加进去之后结算时才报错）。

## 二、购物车管理

在购物车页面可以：

- 修改某一条的**数量**、**勾选/取消勾选**（只对勾选的条目结算）
- **删除**某一条

## 三、结算下单

1. 在购物车里勾选要买的商品，点结算；或在商品详情页直接购买。
2. 结算页可以填**买家备注**（给卖家留言，比如颜色偏好、发货时间要求）。
3. 确认金额后提交，创建订单。

**结算页要选履约方式**（到店自提 / 快递）：

- **到店自提**是默认方式，所有店铺都支持：不需要地址，订单里会显示门店名称、地址和电话。
- **快递配送**只在店铺开启「支持快递」时才能选；选了快递就必须有收货地址
  （可在「收货地址」页添加，支持设置默认地址，最多 20 条）。**自提订单不需要地址。**
- 平台**不计算运费**，订单金额 = 所选商品价格 × 数量 的合计。
- 没有优惠券、积分、红包等抵扣项。

## 四、提交时的两条服务端校验

这两条会直接拒绝下单并给出原因：

1. **库存不足**：限量商品的可售库存不够时无法下单。
   （可售库存 = 总库存 − 已被未付款订单锁定的数量，所以别人刚锁走最后几件时你会被拒。）
2. **不能买自己店铺的商品**：平台禁止自买——用自己账号下自己店铺的订单会被拒绝。
   这是为了防止刷销量和虚假交易。

## 五、幂等键：为什么连点两次不会下两单

下单请求会带一个**幂等键（Idempotency Key）**：

- 同一个买家 + 同一个幂等键 → 服务端**只创建一张订单**，重复提交会直接返回已存在的那张单。
- 数据库层面还有唯一约束兜底（幂等键 + 买家 ID 联合唯一），并发重复提交也拦得住。
- 所以你网络卡顿连点几次「提交订单」，**不会**变成三张订单、也不会重复扣款。

## 六、下单之后

- 订单进入「**待支付**」，**支付时限 2 分钟**。
- 2 分钟内完成支付 → 订单变「已支付」，库存被正式扣减，等待卖家发货。
- 超时未支付 → 系统**自动取消订单并释放库存**，想买需要重新下单。

> **为什么只有 2 分钟**：这是演示环境的配置（`lingmart.order.timeout-ms`，默认 120000 毫秒）。
> 生产环境会调整成更宽松的时长。
> 你可以在订单列表手动点「取消订单」提前取消，同样会释放库存。

## 七、常见问题

- **“购物车里的商品怎么突然显示库存不足了？”** 商品库存被其他人买走或锁定了，实时可售量下降了。
- **“能修改已提交订单的商品或数量吗？”** 不能。请取消后重新下单。
- **“下单后卖家一直不发货怎么办？”** 已支付的订单可以申请退款（见《退款指南》），
  也可以先通过「消息」联系卖家催办。
- **“为什么我不能用另一个账号买自己店里的东西？”** 平台禁止自买，见上文第四节。

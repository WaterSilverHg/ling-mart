# 常见故障排查

按现象查找，先自己试一遍列出的检查点。

## 一、图片上传失败

**可能原因与处理**：

1. **格式不符**：平台按**文件内容**校验图片格式（不只是看扩展名），把 .txt 改成 .jpg 会被拒绝。
   请用真实的 jpg / png 图片。
2. **文件过大**：压缩或裁剪后重试。
3. **上传太频繁**：平台对上传有频率限制（每个用户每分钟最多 20 张），等一下再传。
4. **重新选文件**：有时是浏览器把旧的文件引用缓存住了，重新点「选择文件」再传一次。

上传入口是统一的：商品图、店铺 Logo、头像都走同一个上传接口，所以一处能传别处就能传。

## 二、搜索没有结果 / 我的商品搜不到

**买家侧**：

- 换个更宽泛的关键词（检索匹配的是**商品标题**，卖家措辞不同结果就不同）
- 清空价格区间等筛选条件再搜
- 确认该商品**没有被下架**（下架会立刻从搜索中移除）
- 商品**刚上架**通常是立即能搜到的；若搜索服务临时故障，系统会自动重试写入，稍等即可

**卖家侧**：确认三件事——① 商品**已通过审核**；② 商品**已上架**（通过审核不会自动上架）；
③ 店铺处于**营业状态**。详情见《搜索与浏览》。

## 三、下单失败

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 库存不足 | 限量商品的可售库存被抢光了 | 等卖家补货，或联系卖家 |
| 不能购买自己店铺的商品 | 平台禁止自买 | 用别的账号买，或让朋友代买 |
| 提交后没反应/重复提交 | 网络卡顿 | 幂等键会保证只建一单，去「我的订单」确认一下，不要反复提交 |

## 四、订单支付超时被取消

- 支付时限是 **2 分钟**，超时系统自动取消并释放库存。
- 被取消后**不能恢复**，需要重新下单。
- 如果确实需要更长的支付时间，说明当前配置对你不合适，请联系平台运营。

## 五、申请退款被拒

- 先看提示的**具体原因**：未支付 / 已退款 / 已有申请审核中 / 订单状态不允许，
  这四种都会在提交时被拦下。
- 如果是**卖家拒绝**的，你会看到卖家填写的拒绝原因，可以协商后**修改理由重新申请**。
- 更多细节见《退款指南》。

## 六、聊天发不出消息

- **发送频率限制**：30 秒内最多 30 条，超了会被临时限流，等一下再发。
- 发送失败的消息**不会丢**——气泡会标红显示「发送失败」，点一下可以一键重发。
- **对方看不到消息？** 消息会正常保存，但实时送达需要**对方也在「消息」页面**
  （长连接建立后才会推送）。他下次打开会话就能看到。
- **断线后**：客户端会自动补齐断线期间漏掉的消息，不需要手动刷新页面。

## 七、提示「未登录」或登录状态丢失

- 登录凭证**有效期 120 分钟**，过期后所有请求会被拒绝并跳回登录页，重新登录即可。
- 如果刚登录就提示未登录，检查浏览器是否禁用了本地存储（无痕模式/隐私设置可能导致凭证存不下来）。
- 重新登录后页面状态会重置，**未提交的表单内容需要重填**。

## 八、验证码收不到

- 平台**没有接真实短信通道**。开发/测试环境下验证码会直接显示在页面上或由接口返回，不会真发短信。
- 若页面上也没有显示，确认手机号格式正确（11 位），或稍等重试（发送有频率限制）。

## 九、页面显示「商品不存在」但我知道这个商品还在

- 商品被**下架**了，或**审核状态不是「已通过」**——这两种情况下只有卖家本人能看到，
  其他人访问就是「商品不存在」。
- 这是平台的有意设计（防止靠猜 ID 探测未发布的商品），不是故障。

## 十、浮窗助手答不上来或答错

- 助手的回答基于平台知识库，**可能有误**。涉及金额、订单状态、审核结果的关键信息请**以页面显示为准**。
- 如果助手反复答错同一类问题，说明知识库还没覆盖到，可以向平台运营反馈补充。
- 触发频率限制（每分钟有请求上限）时会提示「操作太频繁」，稍等再问。

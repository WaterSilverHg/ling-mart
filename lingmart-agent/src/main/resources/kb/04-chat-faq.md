# 消息聊天与常见问答 FAQ

## 买卖双方聊天

- 买家与卖家通过「消息」（/chat）实时沟通（页面顶栏「消息」入口），支持会话列表 + 单会话窗口。
- 聊天基于 WebSocket 实时收发，历史记录分页加载。
- 在商品页/订单中点击联系卖家会建立对应会话；对方在你回复后可收到新消息提醒。

## 聊天功能细节

- **发送频率限制**：30 秒内最多发送 30 条消息，超出会被暂时限流。
- **发送失败不会丢内容**：被限流或发送失败时，该条气泡会标红显示「发送失败」并支持一键重发，文字不会丢失。
- **断线自动补拉**：网络中断重连后，客户端会自动补齐断线期间漏掉的消息，不用手动刷新。
- **消息实时送达的前提**：双方**都要打开「消息」页面**（WebSocket 长连接建立后）才能实时收到；
  对方不在线时，消息会正常保存，他下次进入会话即可看到。

## 常见术语

- **幂等键（Idempotency Key）**：下单接口用于防止重复提交的标识。相同买家携带相同幂等键时，服务端只处理一次，
  避免重复扣款、重复建单——这是“为什么我连点两次提交不会下两单”的原因。
- **SKU**：最小库存单元，同一商品不同规格（如颜色/尺码）各是一个 SKU，各自管理价格与库存。
- **不限量商品**：卖家发布商品时选择“不限量”后，该商品不参与库存扣减，理论上可以一直卖；
  数量有限的商品则受库存约束，售罄后无法下单。
- **宽松重审**：修改商品内容或店铺信息后进入「待重审」，**审核期间旧内容照常销售**，通过后新内容才生效。

## 高频问题速答

- **“商品卖光了还能买吗？”**：如果卖家设置的是**不限量**，可以一直买；如果是限量商品，库存为 0 时无法下单，
  需要等卖家补货。提示「库存不足」就是这个原因。
- **“如何退款？”**：**可以自助申请**——在订单详情点「申请退款」并填写原因，由**卖家**审核。
  已支付 / 已发货 / 已完成的订单都能申请；被拒绝后可以修改理由再次申请。
  详见知识库《退款指南》。
- **“上传图片失败/头像不显示？”**：图片有格式与大小校验（按文件内容校验，改扩展名伪装无效）。
  换一张常见格式（jpg/png）的图片重试；仍失败请压缩后再传。
- **“被拒绝开店/商品被拒怎么办？”**：在「我的店铺」或商品管理里查看拒绝原因，按提示修改后重新提交。
  开店被拒是整体拒绝（店铺+商品），可以复用原申请重来。
- **“注册后收不到验证码？”**：确认手机号正确、检查是否被短信拦截。
  平台当前**没有接真实短信通道**，开发/测试环境下验证码会直接显示在页面上。生产环境请联系平台运营。
- **“我的商品为什么搜不到？”**：见知识库《搜索与浏览》——只有**已上架且审核通过**的商品才会出现在搜索结果里。

# 卖家：商品发布、审核与上下架

（本节面向已开通店铺的卖家，路由入口：/seller）

## 一、发布一个新商品

在「卖家中心」→「商品管理」→「发布商品」，填写：

- **商品标题**、**副标题**（检索主要看标题）
- **图文描述**、**商品图片**（支持多图上传）
- **价格**、**库存**（可设为不限量，见下）
- **SKU 规格**：同一商品的不同规格各是一条 SKU，**价格和库存按 SKU 分别管理**

提交后商品进入「**待审核**」，**不会立即出现在首页或搜索结果里**。

## 二、审核状态（商品侧）

商品和店铺一样有独立的审核状态：

| 状态 | 含义 | 对外可见 |
| --- | --- | --- |
| 待审核 | 刚发布，等管理员审核 | 否 |
| 已通过 | 审核通过 | 上架后可见 |
| 已拒绝 | 审核未通过 | 否 |
| 待重审 | 通过后又改了内容 | **旧内容仍可见/可售** |

**审核通过 ≠ 自动上架**：通过审核后还需要**手动「上架」**，商品才会写入搜索索引、对外展示。

## 三、修改商品内容：宽松重审

- 修改商品内容（标题/描述/图片/价格等）后，商品进入「**待重审**」。
- **宽松之处**：重审期间**旧内容照常销售**，不会因为你在改商品就把链接变成「商品不存在」。
- 审核通过后新内容才生效；审核被拒则**丢弃本次修改**，旧内容继续卖。
- **例外**：只改**库存**不触发重审，改完立即生效。

## 四、上下架

- **上架**：商品必须**已通过审核**才能上架；上架后会同步到搜索引擎，用户能搜到。
- **下架**：立即从搜索中移除，但商品数据保留，随时可以重新上架。
- 上下架只影响展示，**不影响已有订单**。

## 五、库存：限量与不限量

发布商品时可以选：

- **不限量**：该商品不参与库存扣减，下单、付款、取消、退款全流程都跳过库存操作，可以一直卖。
  适合虚拟商品、可无限供应的商品。
- **限量**：填写具体数量，下单会锁定库存、付款会扣减、取消/退款会释放或回补。
  库存扣到 0 之后买家会看到「库存不足」，无法下单。
- **改库存不会触发重新审核**，可以随时调整。

> 买家看到的库存是**实时可售量**（总库存减去已被未付款订单锁定的部分），
> 所以「商品页显示有货但下单提示库存不足」通常是因为别人刚刚锁走了最后几件。

## 六、常见问题

- **“我的商品为什么搜不到？”** 三个检查点：① 审核是否通过；② 是否已上架；③ 标题里有没有买家会搜的关键词。
  三者缺一就不会出现在搜索结果里。
- **“商品被拒了还能改吗？”** 能，按拒绝原因修改后重新提交审核即可。
- **“能批量审核商品吗？”** 审核是管理员侧的操作；卖家只能逐个提交，管理员可以批量处理。
- **“一个商品能有几种规格？”** 一个商品（SPU）下可以挂多条 SKU，详情页默认展示前 100 条，
  超出部分点「查看更多 SKU」分页加载。
- **“商品能从店铺里删掉吗？”** 当前版本用「下架」代替删除；下架后不再对外展示。

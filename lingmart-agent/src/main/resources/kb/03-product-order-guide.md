# 商品与订单指南

## 商品发布与审核

- 卖家在「卖家中心」发布商品：填写商品标题、图文描述、价格、库存与 SKU 规格。
- 商品发布后需经管理员审核（管理后台审核商品），审核通过后才会在首页/检索中上架展示。
- 审核期间或未通过的商品不会对外展示；卖家可在商品管理中查看状态并修改重提。

## 买家下单流程

1. 在首页/店铺/检索浏览商品 → 加入购物车，或在商品页直接购买。
2. 进入结算页，可填写**买家备注**（给卖家留言），确认金额后提交。
3. 订单生成后进入「待支付」状态。**支付时限为 2 分钟**——超时未支付，系统会自动取消订单并释放库存。
   想重新购买需要重新下单。
4. 支付成功后可到「我的订单」（/orders）查看与跟踪订单。

> **平台没有「收货地址」字段**：下单只需选商品和数量，不填地址、不填手机号。买卖双方的沟通与履约细节
> 通过「消息」自行协商。**平台也不计算运费**——订单金额就是所选商品的价格合计。

## 订单状态（买家视角）

| 状态 | 含义 | 你能做什么 |
| --- | --- | --- |
| 待支付 | 尚未付款，2 分钟内有效 | 继续支付 / 主动取消 |
| 已支付 | 已付款，等待卖家发货 | 可申请退款 |
| 已发货 | 卖家已发货，等待你收货 | 确认收货 / 可申请退款 |
| 已完成 | 你已确认收货，交易结束 | 仍可申请退款 |
| 已取消 | 超时未支付或你主动取消 | — |
| 已退款 | 退款已通过，交易关闭 | — |

- 卖家在「卖家中心」处理发货；**发货由卖家操作，你无法自行变更状态**。
- **确认收货是买家的动作**：收到货后在订单详情点「确认收货」，订单才变为已完成。
- 「重复提交不会下两单」：下单接口带**幂等键**，同一买家携带相同幂等键只会创建一张订单，
  连点提交不会重复建单、不会重复扣款。
- **不能买自己店铺的商品**：平台禁止自买（防止刷销量），下单时会校验并拒绝。

## 售后与联系

- 订单有疑问（发货、收货、退款等）优先通过「消息」（/chat）联系卖家。
- **退款是可以自助申请的**——已支付 / 已发货 / 已完成的订单都能在订单详情发起退款申请，由卖家审核。
  详见知识库《退款指南》。
- 经营数据与订单明细导出在「卖家中心」操作，买家也可在订单列表导出自己的订单（Excel）。

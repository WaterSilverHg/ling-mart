# 退款指南

退款是**买卖双方协商 + 卖家审核**的流程，买家可以自助发起申请，不需要联系平台管理员。

## 一、买家怎么申请退款

1. 进入「我的订单」（/orders），找到那一笔订单，点开订单详情。
2. 点「申请退款」，**填写退款原因**（必填，不能不写）。
3. 提交后订单进入「退款中」状态，等待**卖家**审核。

## 二、什么情况下能申请（这是会失败的原因）

平台会在提交时逐条校验，**不满足会直接拒绝并给出原因**：

| 校验 | 不通过时的提示 |
| --- | --- |
| 订单必须已支付 | 订单未支付，不能申请退款 |
| 该订单不能已经退款成功 | 该订单已退款 |
| 不能有正在审核中的退款申请 | 已有退款申请审核中，请耐心等待 |
| 订单状态必须是「已支付 / 已发货 / 已完成」 | 当前订单状态不允许申请退款 |
| 必须填写退款原因 | （提示填写原因） |

> **注意**：「待支付」「已取消」的订单**不能**申请退款——待支付的单请直接取消，已取消的单本身没有付款。

## 三、卖家怎么处理

卖家在「卖家中心」→ 订单管理里看到退款申请，选择**通过**或**拒绝**：

- **通过**：订单变为「已退款」，交易关闭。同时系统会**把库存加回去**、并**扣减该商品已累计的销量**。
- **拒绝**：**必须填写拒绝原因**（不填不能提交）。买家能看到这个原因。

## 四、被拒绝之后还能再申请吗？

**可以。** 卖家拒绝后，该订单的退款状态变为「退款被拒绝」，买家可以**修改理由后重新提交申请**；
重新申请时上一次的拒绝原因会被清空，不会干扰本次审核。

## 五、退款到账

- 退款通过后订单状态立刻变为「已退款」，不再计入卖家的销售统计。
- 平台当前使用**模拟支付**（没有对接真实支付渠道），所以退款不涉及真实资金回退，
  「已退款」表示**平台内的交易状态已关闭**，实际资金往来请与卖家线下协商。

## 六、常见问题

- **“卖家一直不处理退款怎么办？”** 先通过「消息」（/chat）催办；卖家拒绝的话你会看到拒绝原因，
  可以据此再协商、再申请。
- **“退款后订单还能看到吗？”** 能。「我的订单」里会保留这条记录，状态显示为「已退款」。
- **“已完成的订单还能退吗？”** 能——「已完成」也在可申请退款的范围内。
- **“能不能只退一部分？”** 当前版本是**整单退款**，不支持部分退款或按商品退。
- **“运费退吗？”** 平台不计运费，订单金额只是商品价格合计，所以不存在运费退还问题。

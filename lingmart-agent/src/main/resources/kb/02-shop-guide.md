# 开店入驻指南

## 如何申请开店

1. 登录后，点击页面右上角用户菜单里的「申请开店」，或在 Copilot 浮窗中说“我要申请开店”，由助手带你跳到申请页。
2. 进入「申请开店」页面（路由 /shop/apply），填写三项店铺信息 + **一份商品清单**：
   - **店铺名称**（必填，全平台唯一，不能与其他店铺重名）
   - **店铺 Logo**（上传图片）
   - **店铺简介**（一句话说明你卖什么）
   - **商品清单**（必填，至少一个商品）：每项含商品标题、价格、库存、图文描述等，逐条填写。
3. 提交后**等待管理员人工审核**。审核是人工逐条进行的，平台**不承诺固定时限**；
   请自行在「我的店铺」（/my-shop）查看进度，不要重复提交。

> **为什么必须附商品清单**：本平台是「审核制」入驻——管理员在审核店铺的同时会逐条审核你申报的商品。
> 只有两者都通过，店铺才开始营业、商品才可售。空店申请不予通过。

## 审核状态与结果

店铺有**两个互相独立的状态**，容易混淆：

- **审核状态**：待审核 / 已通过 / 已拒绝 / 待重审（改过店铺信息或商品内容后会进入待重审）
- **营业状态**：未启用 / 营业中 / 已禁用

- 刚提交时是「待审核」，此时店铺还不营业、商品也不可售。
- 审核通过 → 店铺「营业中」，你被升级为卖家（ROLE_SELLER），申报的商品同时通过审核、可上架销售。
- 审核拒绝 → 是**整体拒绝**（店铺和商品一起）；请查看拒绝原因，修改后重新提交。
  被拒后可以**复用原申请重来**，不需要换账号。

## 修改店铺信息：宽松重审

- 改动店铺信息（店名、简介、Logo）不会立即生效，而是进入「待重审」。
- **宽松之处**：重审期间**旧内容照常营业、商品照常销售**，不会因为你在改资料就把店关掉。
- 只有审核通过后，新内容才正式生效。
- **例外**：只改商品**库存**不触发重审，立即生效。

## 卖家中心

审核通过后，「卖家中心」（/seller）提供：商品管理（发布/编辑/上下架）、订单发货、库存管理、经营数据统计与订单导出。

## 常见问题

- **一个账号能开几家店？** 一家。账号与店铺是一对一关系（数据库唯一约束），已开店/审核中的账号不能再次申请。
- **开店收费吗？** 入驻本身免费，平台当前不收取任何入驻费用。
- **怎么改店铺联系方式？** 平台**没有单独的「联系方式」字段**——店铺对外信息只有名称、Logo、简介三项。
  买家有问题会通过「消息」直接联系你，无需填手机号。
- **店铺能注销/关闭吗？** 当前版本不提供自助注销，店铺「营业状态」由平台管理。

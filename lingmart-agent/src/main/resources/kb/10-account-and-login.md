# 账号：注册、登录与个人资料

## 一、注册

1. 点页面右上角「注册」（路由 /register）。
2. 填写**手机号**，点「发送验证码」。
3. 填入收到的验证码 + **密码** + **昵称**，提交完成注册。

- 手机号全平台唯一，一个手机号只能注册一个账号。
- 密码在服务端加密存储，平台任何人（包括管理员）都看不到明文。
- **收不到验证码？** 平台当前**没有接入真实短信通道**——开发/测试环境下验证码会**直接显示在页面上**
  或由接口返回，不会真的发短信。生产环境需要配置短信服务商，请联系平台运营。

## 二、登录与退出

- 「登录」（/login）用手机号 + 密码。
- 登录成功后得到一个**登录凭证（Token）**，前端自动携带，你不用手动管理。
- **凭证有效期 120 分钟**。过期后请求会返回 401，页面会自动跳回登录页，重新登录即可。
- **退出登录**：用户菜单 →「退出登录」。退出后该凭证会在服务端**立即失效**
  （不只是前端删除），即使有人拿到了旧凭证也用不了。

> **为什么退出后旧凭证就失效了**：服务端会把该凭证的唯一标识加入黑名单，
> 后续任何携带它的请求都会被网关拒绝。这是「退出登录」和「清空本地缓存」的区别。

## 三、个人资料

用户菜单 →「个人资料」可以修改：

- **昵称**
- **头像**（上传图片）

头像和昵称会在你的店铺主页、聊天会话中展示给其他用户看。

## 四、角色与权限

| 角色 | 能做什么 |
| --- | --- |
| 普通买家 | 浏览搜索、加购物车、下单支付、管理自己的订单、申请退款、与卖家聊天 |
| 卖家 | 买家全部功能 + 我的店铺、卖家中心（发布商品、发货、经营数据、订单导出） |
| 管理员 | 独立的管理后台（/admin/review）：审核开店申请、审核商品、查看审核日志 |

- 注册后默认是**买家**；申请开店并通过审核后**自动升级为卖家**。
- 管理员**不参与购物流程**，其后台只有审核功能，没有商城入口。
- **角色变更后需要重新登录才生效**——角色信息包含在登录凭证里。

## 五、常见问题

- **“一个手机号能注册两个账号吗？”** 不能，手机号唯一。
- **“忘记密码怎么办？”** 当前版本**没有自助找回密码**功能，请联系平台运营处理。
- **“能改绑手机号吗？”** 当前版本不支持。
- **“账号能注销吗？”** 当前版本不提供自助注销。
- **“为什么我明明登录了，操作却提示未登录？”** 凭证可能刚好过期（有效期 120 分钟）。
  刷新页面会跳转登录，重新登录即可；未保存的操作内容需要重做一遍。
- **“管理员能看我的密码/帮我改订单吗？”** 不能。密码是加密存储的，
  管理员只能做审核（开店申请、商品），没有代客下单或改订单的权限。

# 搜索与浏览

## 一、首页以「店铺」为入口，不直接列商品

在首页搜索框输入关键词（如「手机」），返回的是**命中的店铺卡片**，而不是一堆商品：
卡片上显示店铺名、在售商品数、该店的最低起售价和一张代表图。

点进店铺卡片 → 进入店铺主页，才看到这家店里匹配的在售商品。

> **为什么这样设计**：轻营是 C2C 平台，同一类商品可能有很多小店在卖。
> 按店铺聚合能让你先看「哪家在卖」，再决定进哪家逛，避免在几十个相似商品里翻页。

## 二、搜索支持什么

- **关键词**：匹配商品标题。中文做了分词处理，所以「苹果」能搜到「苹果手机」这类标题。
- **价格区间**：可设最低价 / 最高价。
- **排序**：可切换不同排序方式。
- **免登录可用**：搜索页不需要登录就能浏览。

**不再支持按分类筛选**：平台已下线商品分类维度（个人闲置交易里粗粒度分类价值有限），
请改用**关键词 + 价格区间**来缩小范围。

## 三、为什么你的商品搜不到（卖家自查）

商品要出现在搜索结果里，必须**同时**满足：

1. **审核状态 = 已通过**（待审核 / 已拒绝 / 待重审的商品不进搜索索引）
2. **已上架**（通过审核但没点上架，也不会出现在搜索里）
3. **店铺处于营业状态**（店铺被禁用则其商品不参与检索）

另外，**下架会立即从搜索中移除**，重新上架后才回来。

## 四、为什么搜不到想要的商品（买家自查）

- **换个说法试试**：检索匹配的是商品**标题**，卖家写的标题措辞不同，搜出来的结果就不同。
  比如搜「二手手机」可能不如搜「手机」命中多。
- **价格区间是不是设太窄**：清空价格条件再搜一次。
- **刚上架的商品**：上架/下架会**同步**写入搜索索引，正常情况下**立即**能在搜索里看到。
  只有在写入搜索失败时（比如搜索服务临时不可用），系统会先记一笔待补偿记录，
  由后台按**指数退避**重试——这种少见情况下，商品要等重试完成后才出现在搜索里。
- **平台商品总量**：如果关键词确实没有对应的在售商品，搜不到是正常的，不是故障。

## 五、商品详情页能看到什么

- 商品标题、副标题、图文描述、多张图片
- **价格与库存**（按 SKU 分别展示）
- **所属店铺**（可点击进店逛其他商品）
- 店铺名与审核状态

**可见性规则**：只有「上架 **且** 审核通过」的商品对所有人可见。
未上架/待审核/已拒绝的商品**只有卖家本人**能预览（用于自己检查），
其他人访问会看到「商品不存在」——这是有意为之，防止靠猜 ID 探测未发布商品。

## 六、常见问题

- **“搜索结果是空的，是系统坏了吗？”** 平台没有匹配的在售商品时返回空结果，这是正常表现，不是报错。
- **“能按分类找商品吗？”** 不能，分类维度已下线，请用关键词 + 价格区间。
- **“能收藏商品/关注店铺吗？”** 当前版本没有收藏与关注功能。
- **“有购物车之外的对比功能吗？”** 没有。看中后加购物车或直接下单。

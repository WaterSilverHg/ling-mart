# 平台能力边界：这些功能目前没有

用户经常问的一些功能，**轻营当前版本并不提供**。这里集中说明，避免误解和无效等待。

## 交易相关

| 功能 | 现状 |
| --- | --- |
| 真实支付 / 在线付款 | **没有**。当前是**模拟支付**，点「支付」只改变平台内的订单状态，不走真实资金渠道 |
| 购物券 / 优惠券 / 满减 | **没有**。订单金额就是商品价格合计，没有任何抵扣项 |
| 积分 / 会员等级 / 成长值 | **没有**。平台刻意不做会员体系 |
| 收货地址簿 | **没有**。下单不收集收货地址，履约细节买卖双方自行协商 |
| 运费计算 / 运费模板 | **没有**。平台不算运费 |
| 部分退款 / 按商品退款 | **没有**。退款是**整单**的 |
| 秒杀 / 拼团 / 预售 | **没有**。这类营销玩法不在当前版本范围内 |
| 收藏商品 / 关注店铺 | **没有** |
| 商品评价 / 评分 / 晒单 | **没有** |
| 物流跟踪 / 快递单号 | **没有**。平台未对接物流，发货只是状态标记 |
| 自动发货 / 虚拟卡密 | **没有** |
| 发票 | **没有** |

## 账号相关

| 功能 | 现状 |
| --- | --- |
| 自助找回密码 | **没有**，忘记密码需联系平台运营 |
| 改绑手机号 | **没有** |
| 自助注销账号 | **没有** |
| 第三方登录（微信/QQ） | **没有**，只有手机号 + 密码 |
| 真实短信验证码 | **没有接短信通道**。开发/测试环境验证码直接显示在页面上 |

## 商品与店铺相关

| 功能 | 现状 |
| --- | --- |
| 商品分类 | **已下线**。改用关键词 + 价格区间检索 |
| 批量上架/批量改价 | **没有**（管理员侧有批量审核商品） |
| 库存预警 / 自动补货 | **没有** |
| 多店铺 | **没有**，一个账号只能开一家店 |
| 店铺自主注销/关闭 | **没有**，店铺营业状态由平台管理 |
| 商品收藏夹 / 对比 | **没有** |
| 商品规格的自定义属性 | 只用 SKU 表达规格（如颜色/尺码），**没有**自定义属性编辑 |

## 平台功能

| 功能 | 现状 |
| --- | --- |
| 面向买家的客服工单 | **没有**。交易问题请通过「消息」联系卖家 |
| 站内通知中心 | **没有**。新消息提醒在浮窗和消息入口体现 |
| 换肤 / 深色模式 | **没有** |
| 手机 App / 小程序 | **没有**，只有网页版 |
| 多语言 | **没有**，界面仅简体中文 |

## 关于「当前版本没有」这件事

如果你问的功能在上面列表里，说明**平台确实不支持**，不是你的操作方式不对，也不是系统故障。
可以留意后续版本更新；如果是开店/商品审核这类流程问题，仍可正常走对应流程解决。
